# OA 系统请假申请验证：日期、时长、审批流程

## 引言

在企业 OA（办公自动化）系统中，请假申请是最常见、也是最容易出错的流程之一。一个看似简单的"请个假"，背后却涉及着复杂的业务规则：

- **日期校验**：开始日期不能晚于结束日期，不能请"过去"的假，不能跨年度请假
- **时长计算**：工作日、周末、法定节假日的区分，半天 vs 全天的精确计算
- **审批流程**：不同职级、不同部门的审批人不同，审批权限需要校验
- **假期余额**：年假余额是否充足，调休假是否过期
- **冲突检测**：同一时间段不能重复申请，与已有的出差、外勤等冲突
- **附件校验**：病假需要医院证明，婚假需要结婚证等

如果这些校验缺失或出现漏洞，轻则审批混乱，重则影响工资计算、假期管理，甚至产生劳动纠纷。

本文以一个真实企业 OA 系统的请假模块为例，讲解如何用 ValidX 建立完整的请假申请验证体系。

## 一、请假申请的业务场景分析

### 1.1 请假类型

| 请假类型 | 说明 | 是否需要证明 | 薪资规则 |
|---------|------|-------------|---------|
| **年假** | 法定带薪年假 | 否 | 全额工资 |
| **病假** | 因疾病休假 | 是（医院证明） | 按病假工资比例 |
| **事假** | 因个人事务休假 | 否 | 无工资 |
| **婚假** | 结婚休假 | 是（结婚证） | 全额工资 |
| **产假** | 生育休假 | 是（医院证明） | 按法定标准 |
| **丧假** | 直系亲属去世 | 否 | 全额工资 |
| **调休** | 加班调休 | 否 | 全额工资 |
| **工伤假** | 因工受伤 | 是（工伤认定） | 按工伤标准 |

### 1.2 请假流程

```
员工提交请假申请
    ↓
校验请假资格（余额、时间冲突、类型限制）
    ↓
自动计算时长（工作日、含/不含周末、节假日）
    ↓
确定审批人（直接领导 → 部门负责人 → HR）
    ↓
审批流推进
    ↓
审批结果通知
```

### 1.3 常见请假陷阱

| 陷阱 | 场景 | 后果 |
|------|------|------|
| 日期倒置 | 结束日期早于开始日期 | 系统计算出负数时长，工资结算错误 |
| 跨年度请假 | 12月31日请假到次年1月2日 | 年假统计跨年度，余额归属混乱 |
| 重复请假 | 同一时间段提交多个申请 | 员工实际未在岗，但只扣一次工资 |
| 假期余额透支 | 年假余额 3 天，却申请 5 天 | 超支使用年假，公司权益受损 |
| 证明材料缺失 | 病假未上传医院证明 | 无法判定是否为合法病假 |
| 审批人错误 | 新领导未同步到系统 | 审批流卡住，影响业务 |

## 三、核心验证规则实现

### 3.1 日期合法性校验

日期校验是请假申请中最基础也是最关键的一环：

```java
@Service
public class LeaveDateValidator {

    @Autowired
    private HolidayService holidayService;

    /**
     * 校验请假日期的合法性
     */
    public void validateLeaveDate(String startDateStr, String endDateStr, 
                                   String startHalf, String endHalf) {
        ValidX chain = ValidX.init().withLocale(Locale.SIMPLIFIED_CHINESE);

        LocalDate startDate = LocalDate.parse(startDateStr);
        LocalDate endDate = LocalDate.parse(endDateStr);

        // 规则 1：开始日期不能晚于结束日期
        if (startDate.isAfter(endDate)) {
            chain.field("请假日期").fail("开始日期不能晚于结束日期");
        }

        // 规则 2：开始日期不能是过去的日期（允许当天）
        if (startDate.isBefore(LocalDate.now())) {
            chain.field("开始日期").fail("不能申请过去日期的请假");
        }

        // 规则 3：请假时长不能超过上限（如 30 天）
        long days = ChronoUnit.DAYS.between(startDate, endDate) + 1;
        if (days > 30) {
            chain.field("请假时长").fail("单次请假不能超过 30 天");
        }

        // 规则 4：不能跨年请假（公司政策，可选）
        if (startDate.getYear() != endDate.getYear()) {
            chain.field("请假日期").fail("不支持跨年度请假，请分两次申请");
        }

        // 规则 5：开始时段和结束时段不能都为下午（同一天）
        if (startDate.equals(endDate) && 
            "PM".equals(startHalf) && 
            "AM".equals(endHalf)) {
            chain.field("请假时段").fail("同一天请假，开始时段不能为下午而结束时段为上午");
        }

        if (!chain.passed()) {
            throw new LeaveException(chain.getErrors());
        }
    }
}
```

### 3.2 请假时长计算

请假时长不是简单的"结束日期 - 开始日期"，需要考虑工作日、周末、节假日：

```java
@Service
public class LeaveDurationCalculator {

    @Autowired
    private HolidayService holidayService;

    /**
     * 计算请假天数（精确到半天）
     */
    public BigDecimal calculateLeaveDays(String startDateStr, String endDateStr,
                                         String startHalf, String endHalf) {
        LocalDate startDate = LocalDate.parse(startDateStr);
        LocalDate endDate = LocalDate.parse(endDateStr);

        BigDecimal totalDays = BigDecimal.ZERO;
        LocalDate current = startDate;

        while (!current.isAfter(endDate)) {
            // 跳过周末
            if (isWeekend(current)) {
                current = current.plusDays(1);
                continue;
            }

            // 跳过法定节假日
            if (holidayService.isHoliday(current)) {
                current = current.plusDays(1);
                continue;
            }

            // 计算当天时长
            if (current.equals(startDate) && current.equals(endDate)) {
                // 开始和结束是同一天
                if (startHalf.equals(endHalf)) {
                    // 同一天上午到上午 或 下午到下午 = 半天
                    totalDays = totalDays.add(new BigDecimal("0.5"));
                } else {
                    // 同一天上午到下午 = 一天
                    totalDays = totalDays.add(BigDecimal.ONE);
                }
            } else if (current.equals(startDate)) {
                // 开始日期
                totalDays = totalDays.add("AM".equals(startHalf) ? BigDecimal.ONE : new BigDecimal("0.5"));
            } else if (current.equals(endDate)) {
                // 结束日期
                totalDays = totalDays.add("PM".equals(endHalf) ? BigDecimal.ONE : new BigDecimal("0.5"));
            } else {
                // 中间日期 = 全天
                totalDays = totalDays.add(BigDecimal.ONE);
            }

            current = current.plusDays(1);
        }

        return totalDays;
    }

    private boolean isWeekend(LocalDate date) {
        DayOfWeek dayOfWeek = date.getDayOfWeek();
        return dayOfWeek == DayOfWeek.SATURDAY || dayOfWeek == DayOfWeek.SUNDAY;
    }
}
```

### 3.3 假期余额校验

```java
@Service
public class LeaveBalanceValidator {

    @Autowired
    private EmployeeLeaveBalanceRepository balanceRepository;

    /**
     * 校验假期余额是否充足
     */
    public void validateLeaveBalance(String employeeNo, String leaveType, BigDecimal requestDays) {
        ValidX chain = ValidX.init().withLocale(Locale.SIMPLIFIED_CHINESE);

        // 年假、调休等需要校验余额
        if (LeaveType.ANNUAL.getCode().equals(leaveType) ||
            LeaveType.COMPENSATORY.getCode().equals(leaveType)) {

            EmployeeLeaveBalance balance = balanceRepository
                .findByEmployeeNoAndYear(employeeNo, LocalDate.now().getYear());

            if (balance == null) {
                chain.field("假期余额").fail("未查询到您的假期余额信息");
                throw new LeaveException(chain.getErrors());
            }

            BigDecimal remaining = balance.getTotalDays()
                .subtract(balance.getUsedDays())
                .subtract(balance.getPendingDays());

            // 校验余额是否充足（考虑审批中的申请）
            if (requestDays.compareTo(remaining) > 0) {
                chain.field("假期余额").fail(
                    String.format("假期余额不足。您当前可用 %s 天，本次申请 %s 天",
                        remaining, requestDays));
            }

            // 校验调休假是否过期
            if (LeaveType.COMPENSATORY.getCode().equals(leaveType) && 
                balance.isExpired()) {
                chain.field("调休假").fail("您的调休假已过期，无法申请");
            }
        }

        // 婚假：校验是否在有效期内（如结婚一年内）
        if (LeaveType.MARRIAGE.getCode().equals(leaveType)) {
            validateMarriageLeaveEligibility(employeeNo, chain);
        }

        // 产假：校验是否符合条件
        if (LeaveType.MATERNITY.getCode().equals(leaveType)) {
            validateMaternityLeaveEligibility(employeeNo, chain);
        }

        if (!chain.passed()) {
            throw new LeaveException(chain.getErrors());
        }
    }

    private void validateMarriageLeaveEligibility(String employeeNo, ValidX chain) {
        Employee employee = employeeRepository.findByEmployeeNo(employeeNo);
        if (employee.getMarriageDate() == null) {
            chain.field("婚假").fail("系统中未登记结婚日期，无法申请婚假");
            return;
        }

        LocalDate marriageDate = employee.getMarriageDate();
        LocalDate now = LocalDate.now();

        // 婚假一般需在结婚一年内申请
        if (marriageDate.plusYears(1).isBefore(now)) {
            chain.field("婚假").fail("婚假需在结婚一年内申请");
        }
    }
}
```

### 3.4 冲突检测

```java
@Service
public class LeaveConflictDetector {

    @Autowired
    private LeaveApplicationRepository leaveRepository;

    /**
     * 检测请假时间冲突
     */
    public void detectConflicts(String employeeNo, String startDateStr, String endDateStr,
                                String startHalf, String endHalf) {
        ValidX chain = ValidX.init().withLocale(Locale.SIMPLIFIED_CHINESE);

        LocalDate startDate = LocalDate.parse(startDateStr);
        LocalDate endDate = LocalDate.parse(endDateStr);

        // 查询员工在时间段内已有的请假申请
        List<LeaveApplication> existingLeaves = leaveRepository
            .findByEmployeeNoAndDateRange(employeeNo, startDate, endDate);

        for (LeaveApplication existing : existingLeaves) {
            // 状态校验：只考虑已审批通过和审批中的申请
            if (existing.getStatus() == LeaveStatus.REJECTED ||
                existing.getStatus() == LeaveStatus.CANCELLED) {
                continue;
            }

            // 日期重叠检测
            boolean dateOverlap = !startDate.isAfter(existing.getEndDate()) &&
                                  !endDate.isBefore(existing.getStartDate());

            if (dateOverlap) {
                chain.field("请假时间").fail(
                    String.format("与您 %s 至 %s 的【%s】申请冲突，请调整时间",
                        existing.getStartDate(), existing.getEndDate(),
                        existing.getLeaveTypeName()));
            }
        }

        // 检测与出差的冲突
        List<BusinessTrip> trips = tripRepository
            .findByEmployeeNoAndDateRange(employeeNo, startDate, endDate);

        for (BusinessTrip trip : trips) {
            chain.field("请假时间").fail(
                String.format("与您 %s 至 %s 的【出差】安排冲突",
                    trip.getStartDate(), trip.getEndDate()));
        }

        if (!chain.passed()) {
            throw new LeaveException(chain.getErrors());
        }
    }
}
```

### 3.5 审批流程校验

```java
@Service
public class LeaveApprovalValidator {

    @Autowired
    private EmployeeService employeeService;

    @Autowired
    private DepartmentService departmentService;

    /**
     * 确定并校验审批人
     */
    public List<Approver> determineApprovers(String employeeNo, BigDecimal leaveDays) {
        ValidX chain = ValidX.init().withLocale(Locale.SIMPLIFIED_CHINESE);

        Employee employee = employeeService.findByEmployeeNo(employeeNo);
        List<Approver> approvers = new ArrayList<>();

        // 规则 1：直接领导审批（必审）
        Employee directManager = employee.getDirectManager();
        if (directManager == null) {
            chain.field("审批人").fail("您的直接领导信息未配置，请联系 HR");
        } else {
            approvers.add(new Approver(directManager.getEmployeeNo(), "直接领导"));
        }

        // 规则 2：部门负责人审批（请假超过 3 天）
        if (leaveDays.compareTo(new BigDecimal("3")) > 0) {
            Employee deptManager = departmentService.getManager(employee.getDepartmentId());
            if (deptManager != null) {
                approvers.add(new Approver(deptManager.getEmployeeNo(), "部门负责人"));
            }
        }

        // 规则 3：HR 审批（请假超过 7 天）
        if (leaveDays.compareTo(new BigDecimal("7")) > 0) {
            approvers.add(new Approver("HR", "人力资源部"));
        }

        // 规则 4：病假超过 3 天需 HR 审批
        if (LeaveType.SICK.getCode().equals(employee.getLeaveType()) &&
            leaveDays.compareTo(new BigDecimal("3")) > 0) {
            // 去重判断
            boolean hasHr = approvers.stream().anyMatch(a -> "HR".equals(a.getRole()));
            if (!hasHr) {
                approvers.add(new Approver("HR", "人力资源部"));
            }
        }

        // 规则 5：校验审批人是否有审批权限
        for (Approver approver : approvers) {
            if (!approver.hasApprovalPermission(employeeNo)) {
                chain.field("审批人").fail(
                    String.format("审批人【%s】无权限审批您的请假申请", approver.getName()));
            }
        }

        if (!chain.passed()) {
            throw new LeaveException(chain.getErrors());
        }

        return approvers;
    }
}
```

## 四、完整的请假申请 Service

```java
@Service
@RequiredArgsConstructor
public class LeaveApplicationService {

    private final LeaveDateValidator dateValidator;
    private final LeaveDurationCalculator durationCalculator;
    private final LeaveBalanceValidator balanceValidator;
    private final LeaveConflictDetector conflictDetector;
    private final LeaveApprovalValidator approvalValidator;
    private final LeaveApplicationRepository leaveRepository;

    /**
     * 提交请假申请
     */
    @Transactional
    public LeaveResult applyLeave(@Valid LeaveApplyRequest request) {
        String employeeNo = request.getEmployeeNo();
        String startDate = request.getStartDate();
        String endDate = request.getEndDate();
        String startHalf = request.getStartHalf();
        String endHalf = request.getEndHalf();
        String leaveType = request.getLeaveType();

        // ========== Step 1: 日期合法性校验 ==========
        dateValidator.validateLeaveDate(startDate, endDate, startHalf, endHalf);

        // ========== Step 2: 计算请假时长 ==========
        BigDecimal leaveDays = durationCalculator.calculateLeaveDays(
            startDate, endDate, startHalf, endHalf);

        // 校验时长必须大于 0
        if (leaveDays.compareTo(BigDecimal.ZERO) <= 0) {
            throw new LeaveException(List.of("请假时长必须大于 0 天"));
        }

        // ========== Step 3: 假期余额校验 ==========
        balanceValidator.validateLeaveBalance(employeeNo, leaveType, leaveDays);

        // ========== Step 4: 冲突检测 ==========
        conflictDetector.detectConflicts(employeeNo, startDate, endDate, startHalf, endHalf);

        // ========== Step 5: 审批流程校验 ==========
        List<Approver> approvers = approvalValidator.determineApprovers(employeeNo, leaveDays);

        // ========== Step 6: 生成请假申请 ==========
        LeaveApplication application = LeaveApplication.create(
            employeeNo, leaveType, startDate, endDate,
            startHalf, endHalf, leaveDays, request.getReason(),
            request.getAttachments(), request.getHandoverEmployeeNo()
        );

        // 设置审批流程
        application.setApprovalChain(approvers);

        // ========== Step 7: 保存并启动审批流 ==========
        leaveRepository.save(application);
        approvalService.startApprovalFlow(application);

        return LeaveResult.success(application.getLeaveNo(), approvers);
    }
}
```

## 五、常见坑与规避方案

### 5.1 跨天半天请假计算错误

**问题**：员工请"周五下午到周一上午"的假，系统计算为 3 天。

**解决方案**：

```java
public BigDecimal calculateLeaveDays(LocalDate startDate, LocalDate endDate,
                                     String startHalf, String endHalf) {
    BigDecimal totalDays = BigDecimal.ZERO;
    LocalDate current = startDate;

    while (!current.isAfter(endDate)) {
        // ... 跳过周末和节假日 ...

        if (current.equals(startDate) && current.equals(endDate)) {
            // 同一天
            if (startHalf.equals(endHalf)) {
                totalDays = totalDays.add(new BigDecimal("0.5"));
            } else {
                totalDays = totalDays.add(BigDecimal.ONE);
            }
        } else if (current.equals(startDate)) {
            // 开始日期
            totalDays = totalDays.add(
                "AM".equals(startHalf) ? BigDecimal.ONE : new BigDecimal("0.5"));
        } else if (current.equals(endDate)) {
            // 结束日期
            totalDays = totalDays.add(
                "PM".equals(endHalf) ? BigDecimal.ONE : new BigDecimal("0.5"));
        } else {
            totalDays = totalDays.add(BigDecimal.ONE);
        }

        current = current.plusDays(1);
    }

    return totalDays;
}
```

### 5.2 审批流中审批人变更

**问题**：员工提交申请后，直接领导调岗或离职，审批流卡住。

**解决方案**：

```java
@Service
public class LeaveApprovalService {

    /**
     * 审批前校验审批人是否仍有效
     */
    public void validateApproverBeforeAction(String leaveNo, String approverNo) {
        LeaveApplication leave = leaveRepository.findByLeaveNo(leaveNo);

        // 校验审批人是否仍是该员工的直接领导
        Employee employee = employeeService.findByEmployeeNo(leave.getEmployeeNo());
        Employee currentManager = employee.getDirectManager();

        if (currentManager == null || !currentManager.getEmployeeNo().equals(approverNo)) {
            // 审批人已变更，重新确定审批人
            List<Approver> newApprovers = approvalValidator
                .determineApprovers(leave.getEmployeeNo(), leave.getLeaveDays());
            leave.setApprovalChain(newApprovers);
            leaveRepository.save(leave);

            // 通知新的审批人
            notificationService.notifyNewApprover(leave);
        }
    }
}
```

### 5.3 假期余额并发扣减

**问题**：员工同时提交两个请假申请，都通过了余额校验，导致超支。

**解决方案**：

```java
@Service
public class LeaveBalanceService {

    @Transactional
    @Retryable(value = OptimisticLockingFailureException.class, maxAttempts = 3)
    public void deductLeaveBalance(String employeeNo, int year, BigDecimal days) {
        EmployeeLeaveBalance balance = balanceRepository
            .findByEmployeeNoAndYearWithLock(employeeNo, year);

        BigDecimal remaining = balance.getTotalDays()
            .subtract(balance.getUsedDays())
            .subtract(balance.getPendingDays());

        if (days.compareTo(remaining) > 0) {
            throw new LeaveException(List.of("假期余额不足"));
        }

        balance.setPendingDays(balance.getPendingDays().add(days));
        balanceRepository.save(balance);
    }
}
```

## 六、总结

OA 系统的请假申请虽然是一个常见的业务场景，但其背后的验证逻辑却非常复杂，涉及日期计算、余额管理、冲突检测、审批流程等多个维度。通过 ValidX 的链式 API，可以将这些复杂的业务规则清晰地组织起来，保证验证逻辑的**可读性**和**可维护性**。

| 校验维度 | 核心规则 | ValidX 工具 |
|---------|---------|-----------|
| 日期校验 | 开始≤结束、不早于今天、不跨年、时段合理 | 链式 API（`isAfter`、`isBefore`） |
| 时长计算 | 排除周末和节假日、精确到半天 | 自定义计算逻辑 + ValidX 校验 |
| 余额校验 | 余额充足、调休假未过期、婚假在有效期内 | 链式 API（`isGreaterThan`） |
| 冲突检测 | 与已有请假、出差不重叠 | 链式 API（`fail`） |
| 审批流程 | 按天数确定审批人、校验审批权限 | 链式 API + 自定义逻辑 |
| 并发安全 | 乐观锁防止超支 | 数据库乐观锁 |

通过 ValidX 的分层校验策略，可以确保请假申请在**入口处拦截非法请求**、**业务层保证逻辑正确**、**持久化层防止并发问题**，最终实现安全、可靠的 OA 请假流程。
