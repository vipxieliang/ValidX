## 概述

在电商系统中，优惠券是拉新、促活、清库存的核心工具。但优惠券的验证逻辑远比"输入一个码，减点钱"复杂——它涉及**券码格式校验、使用条件匹配、有效期控制、状态机流转、互斥规则**等多个维度。

如果你做过电商系统，一定遇到过这些问题：

- 用户输入的 `COUPON2024`，系统怎么知道它是"满100减20"还是"8折券"？
- 用户同时用了两张"满减券"，系统怎么判断能不能叠加？
- 券上写"有效期至2024-12-31"，是到23:59:59还是00:00:00？
- 用户把商品加入购物车后过了几天才下单，券还能用吗？

本文从优惠券的编码规则讲起，到 ValidX 的注解和链式 API 在各层的校验策略，再到一个完整的下单验证流程，帮你建立一套完整的优惠券验证体系。

## 一、优惠券的本质：电商系统的"价格调节器"

### 1.1 优惠券的类型

| 类型 | 描述 | 示例 |
|------|------|------|
| **满减券** | 满X元减Y元 | 满100减20 |
| **折扣券** | 按比例折扣 | 8折、9折 |
| **无门槛券** | 不限金额，直接抵扣 | 立减10元 |
| **品类券** | 仅限指定品类使用 | 仅限数码品类 |
| **店铺券** | 仅限指定店铺使用 | 仅限"XX旗舰店" |
| **新人券** | 仅限新用户 | 首单立减50 |

### 1.2 优惠券的生命周期

```
┌──────────┐    ┌──────────┐    ┌──────────    ┌──────────┐
│  未开始   │ →  │  可用    │ →  │  已使用  │ →  │  已过期  │
│ (UPCOMING)│    │(AVAILABLE)│   │ (USED)   │    │(EXPIRED) │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
       ↑                                         ↗
       └───────────── 已作废 (REVOKED) ──────────┘
```

### 1.3 优惠券验证的三个核心维度

| 维度 | 校验内容 | 工具 |
|------|---------|------|
| **券码** | 格式、是否存在、是否已使用 | ValidX 注解 + 链式 API |
| **使用条件** | 订单金额、品类、店铺、用户身份 | ValidX 链式 API |
| **有效期** | 领取时间、使用时间是否在有效期内 | ValidX 时间注解 |

## 二、券码格式：从编码规则到正则校验

### 2.1 券码的编码规则

优惠券码（Coupon Code）通常遵循以下规则：

| 规则 | 说明 | 示例 |
|------|------|------|
| 长度 | 8-16位 | `COUPON2024`、`SAVE20NOW` |
| 字符 | 大写字母 + 数字 | `A-Z`、`0-9` |
| 前缀 | 表示类型 | `NEW`（新人券）、`SAVE`（满减券） |
| 后缀 | 表示金额或折扣 | `20`（减20元）、`80`（8折） |
| 分隔符 | 可选 | `-`、`_` | 无 |

### 2.2 券码的正则校验

```java
public class CouponCode {

    /**
     * 优惠券码格式：8-16位大写字母和数字
     */
    public static final String COUPON_CODE_PATTERN = "^[A-Z0-9]{8,16}$";

    private final String value;

    public CouponCode(String value) {
        ValidX chain = ValidX.init()
                .withLocale(Locale.SIMPLIFIED_CHINESE)
                .field("优惠券码")
                .isNotBlank(value)
                .matchesPattern(value, COUPON_CODE_PATTERN);

        if (!chain.passed()) {
            throw new IllegalArgumentException(chain.getErrors().get(0));
        }

        this.value = value;
    }

    public String getValue() {
        return value;
    }
}
```

### 2.3 在 DTO 中使用注解校验

```java
public class UseCouponRequest {

    @NotBlank(message = "优惠券码不能为空")
    @Pattern(regexp = CouponCode.COUPON_CODE_PATTERN, 
             message = "优惠券码格式不正确，应为8-16位大写字母和数字")
    private String couponCode;

    @NotNull(message = "订单ID不能为空")
    @Min(value = 1, message = "订单ID必须大于0")
    private Long orderId;
}
```

## 三、使用条件校验：满减、折扣、品类的业务规则

### 3.1 优惠券使用条件的结构

```java
public class Coupon {

    private CouponId id;
    private CouponCode code;
    private CouponType type;           // 满减、折扣、无门槛
    private Money minimumOrderAmount;  // 最低订单金额
    private Money discountAmount;      // 优惠金额
    private BigDecimal discountRate;   // 折扣比例
    private List<CategoryId> applicableCategories;  // 适用品类
    private List<ShopId> applicableShops;          // 适用店铺
    private UserType applicableUserType;            // 适用用户类型
    private LocalDateTime startTime;
    private LocalDateTime endTime;
    private CouponStatus status;
    private int usageLimit;            // 总使用次数限制
    private int usageCount;            // 已使用次数
    private int userUsageLimit;        // 单个用户使用次数限制
}
```

### 3.2 使用条件校验

```java
@Service
public class CouponValidationService {

    @Autowired
    private CouponRepository couponRepository;
    @Autowired
    private OrderService orderService;
    @Autowired
    private UserService userService;

    public void validateCouponUsage(String couponCodeStr, Long orderId, Long userId) {
        // 1. 构造值对象（自校验）
        CouponCode couponCode = new CouponCode(couponCodeStr);

        // 2. 查询优惠券
        Coupon coupon = couponRepository.findByCode(couponCode.getValue())
                .orElseThrow(() -> new CouponNotFoundException("优惠券不存在"));

        // 3. 查询订单
        Order order = orderService.getOrder(orderId);

        ValidX chain = ValidX.init()
                .withLocale(Locale.SIMPLIFIED_CHINESE);

        // 4. 校验优惠券状态
        if (coupon.getStatus() != CouponStatus.AVAILABLE) {
            chain.field("优惠券状态").fail("优惠券不可用");
        }

        // 5. 校验有效期
        LocalDateTime now = LocalDateTime.now();
        if (now.isBefore(coupon.getStartTime())) {
            chain.field("有效期").fail("优惠券尚未开始");
        }
        if (now.isAfter(coupon.getEndTime())) {
            chain.field("有效期").fail("优惠券已过期");
        }

        // 6. 校验最低订单金额
        if (coupon.getMinimumOrderAmount() != null 
                && order.getTotalAmount().compareTo(coupon.getMinimumOrderAmount()) < 0) {
            chain.field("订单金额").fail(
                String.format("订单金额不足，当前订单：%s，最低要求：%s",
                    order.getTotalAmount(), coupon.getMinimumOrderAmount()));
        }

        // 7. 校验适用品类
        if (!coupon.getApplicableCategories().isEmpty()) {
            boolean hasApplicableItem = order.getItems().stream()
                    .anyMatch(item -> coupon.getApplicableCategories()
                            .contains(item.getCategoryId()));
            if (!hasApplicableItem) {
                chain.field("适用品类").fail("订单中没有符合优惠券适用品类的商品");
            }
        }

        // 8. 校验适用店铺
        if (!coupon.getApplicableShops().isEmpty()) {
            boolean hasApplicableShop = order.getItems().stream()
                    .anyMatch(item -> coupon.getApplicableShops()
                            .contains(item.getShopId()));
            if (!hasApplicableShop) {
                chain.field("适用店铺").fail("订单中没有符合优惠券适用店铺的商品");
            }
        }

        // 9. 校验用户类型
        if (coupon.getApplicableUserType() != null) {
            User user = userService.getUser(userId);
            if (user.getType() != coupon.getApplicableUserType()) {
                chain.field("用户类型").fail("当前用户类型不适用此优惠券");
            }
        }

        // 10. 校验使用次数限制
        if (coupon.getUsageCount() >= coupon.getUsageLimit()) {
            chain.field("使用次数").fail("优惠券已达使用上限");
        }

        // 11. 校验单个用户使用次数
        int userUsageCount = couponRepository.countUsageByUser(coupon.getId(), userId);
        if (userUsageCount >= coupon.getUserUsageLimit()) {
            chain.field("使用次数").fail("您已达到该优惠券的使用次数上限");
        }

        if (!chain.passed()) {
            throw new CouponValidationException(chain.getErrors());
        }
    }
}
```

## 四、有效期校验：时间边界的精确控制

### 4.1 有效期的两种模式

| 模式 | 描述 | 示例 |
|------|------|------|
| **固定有效期** | 券上写死起止时间 | 2024-01-01 至 2024-12-31 |
| **领取后有效期** | 领取后N天内有效 | 领取后7天内有效 |

### 4.2 有效期校验

```java
@Service
public class CouponExpirationService {

    /**
     * 检查优惠券是否在有效期内
     */
    public boolean isCouponValid(Coupon coupon) {
        LocalDateTime now = LocalDateTime.now();
        return !now.isBefore(coupon.getStartTime()) 
            && !now.isAfter(coupon.getEndTime());
    }

    /**
     * 计算优惠券的剩余有效期
     */
    public Duration getRemainingTime(Coupon coupon) {
        LocalDateTime now = LocalDateTime.now();
        if (now.isAfter(coupon.getEndTime())) {
            return Duration.ZERO;
        }
        return Duration.between(now, coupon.getEndTime());
    }
}
```

### 4.3 有效期边界问题

| 问题 | 描述 | 解决方案 |
|------|------|---------|
| **精确到秒** | "2024-12-31"是到23:59:59还是00:00:00？ | 统一规则：结束日期为23:59:59 |
| **时区问题** | 用户在北京，服务器在UTC | 统一使用用户时区计算 |
| **领取后有效期** | 用户1月1日领取，7天有效，是到1月7日还是1月8日？ | 统一规则：领取当日算第一天 |
| **闰年2月** | 2月29日领取，30天有效 | 注意闰年处理 |

### 6.2 完整代码

```java
@Service
public class OrderCouponService {

    @Autowired
    private CouponRepository couponRepository;
    @Autowired
    private OrderRepository orderRepository;
    @Autowired
    private UserRepository userRepository;

    @Transactional
    public Order applyCoupon(Long orderId, String couponCodeStr, Long userId) {
        // 1. 券码格式校验（值对象自校验）
        CouponCode couponCode = new CouponCode(couponCodeStr);

        // 2. 查询优惠券
        Coupon coupon = couponRepository.findByCode(couponCode.getValue())
                .orElseThrow(() -> new CouponNotFoundException("优惠券不存在"));

        // 3. 查询订单
        Order order = orderRepository.findById(orderId)
                .orElseThrow(() -> new EntityNotFoundException("订单不存在"));

        // 4. 验证优惠券使用
        validateCouponUsage(coupon, order, userId);

        // 5. 计算优惠后金额
        Money discountAmount = calculateDiscount(coupon, order);
        Money finalAmount = order.getTotalAmount().subtract(discountAmount);

        // 6. 更新订单
        order.setCouponId(coupon.getId());
        order.setDiscountAmount(discountAmount);
        order.setFinalAmount(finalAmount);
        order.setCouponCode(couponCode.getValue());

        // 7. 更新优惠券使用次数
        coupon.setUsageCount(coupon.getUsageCount() + 1);
        if (coupon.getUsageCount() >= coupon.getUsageLimit()) {
            coupon.setStatus(CouponStatus.USED);
        }
        couponRepository.save(coupon);

        return orderRepository.save(order);
    }

    private void validateCouponUsage(Coupon coupon, Order order, Long userId) {
        ValidX chain = ValidX.init()
                .withLocale(Locale.SIMPLIFIED_CHINESE);

        // 状态校验
        if (coupon.getStatus() != CouponStatus.AVAILABLE) {
            chain.field("优惠券状态").fail("优惠券不可用");
        }

        // 有效期校验
        LocalDateTime now = LocalDateTime.now();
        if (now.isBefore(coupon.getStartTime())) {
            chain.field("有效期").fail("优惠券尚未开始");
        }
        if (now.isAfter(coupon.getEndTime())) {
            chain.field("有效期").fail("优惠券已过期");
        }

        // 最低订单金额
        if (coupon.getMinimumOrderAmount() != null 
                && order.getTotalAmount().compareTo(coupon.getMinimumOrderAmount()) < 0) {
            chain.field("订单金额").fail(
                String.format("订单金额不足，当前：%s，最低要求：%s",
                    order.getTotalAmount(), coupon.getMinimumOrderAmount()));
        }

        // 使用次数
        if (coupon.getUsageCount() >= coupon.getUsageLimit()) {
            chain.field("使用次数").fail("优惠券已达使用上限");
        }

        // 单个用户次数
        int userUsageCount = couponRepository.countUsageByUser(coupon.getId(), userId);
        if (userUsageCount >= coupon.getUserUsageLimit()) {
            chain.field("使用次数").fail("您已达到该优惠券的使用次数上限");
        }

        if (!chain.passed()) {
            throw new CouponValidationException(chain.getErrors());
        }
    }

    private Money calculateDiscount(Coupon coupon, Order order) {
        switch (coupon.getType()) {
            case FIXED_AMOUNT:
                // 固定金额减免
                return coupon.getDiscountAmount();
            case PERCENTAGE:
                // 按比例折扣
                BigDecimal discount = order.getTotalAmount().getAmount()
                        .multiply(coupon.getDiscountRate());
                return new Money(discount);
            case NO_THRESHOLD:
                // 无门槛
                return coupon.getDiscountAmount();
            default:
                throw new IllegalArgumentException("未知的优惠券类型");
        }
    }
}
```

## 七、常见坑与最佳实践

### 7.1 常见坑

| 坑 | 描述 | 解决方案 |
|---|------|---------|
| **券码大小写** | 用户输入 `coupon2024`，系统只认 `COUPON2024` | 统一转大写 |
| **过期时间边界** | "2024-12-31"到底算不算过期？ | 统一规则：结束日期为23:59:59 |
| **并发使用** | 两张优惠券同时被使用 | 数据库乐观锁 |
| **重复计算** | 用户多次使用同一张券 | 已使用状态校验 |
| **负数金额** | 优惠后金额为负数 | 最低0元校验 |
| **叠加规则** | 多张券能否叠加使用？ | 明确规则并校验 |

### 7.2 最佳实践

1. **券码统一转大写**：避免大小写问题；
2. **有效期精确到秒**："2024-12-31" = "2024-12-31T23:59:59"；
3. **数据库加乐观锁**：防止并发导致超用；
4. **优惠金额不能为负**：最低为0元；
5. **明确叠加规则**：哪些券可以叠加，哪些不能；
6. **使用记录留痕**：方便审计和排查。
