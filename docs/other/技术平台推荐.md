# 技术平台推荐

## 国内平台

- **掘金**：https://juejin.cn/ - 面向互联网技术人的内容分享平台
- **思否（SegmentFault）**：https://segmentfault.com/ - 中文开发者社区
- **CSDN**：https://www.csdn.net/ - 中国最大的IT社区和服务平台
- **开源中国**：https://www.oschina.net/ - 中文开源技术交流社区
- **V2EX**：https://www.v2ex.com/ - 创意工作者社区，技术讨论氛围很好
- **博客园**：https://www.cnblogs.com/ - 老牌技术博客平台
- **知乎**：https://www.zhihu.com/ - 综合问答平台，技术话题也很活跃
- **InfoQ**：https://www.infoq.cn/ - 专注于软件开发领域的知识与创新
- **腾讯云开发者社区**：https://cloud.tencent.com/developer
- **阿里云开发者社区**：https://developer.aliyun.com/

## 国外平台

- **Stack Overflow**：https://stackoverflow.com/ - 最大的编程问答社区 yes
- **GitHub**：https://github.com/ - 代码托管和开发者社交平台
- **Dev.to**：https://dev.to/ - 开发者社区，内容质量高   yes
- **Medium**：https://medium.com/ - 有大量技术博客文章   yes
- **Hacker News**：https://news.ycombinator.com/ - Y Combinator的技术新闻社区
- **Reddit**：https://www.reddit.com/ - 特别是 r/programming、r/coding 等板块
- **Hashnode**：https://hashnode.com/ - 专注于开发者的博客平台
- **freeCodeCamp**：https://www.freecodecamp.org/ - 学习编程和技术文章
- **DZone**：https://dzone.com/ - 开发者资讯和技术文章
- **CodeProject**：https://www.codeproject.com/ - 代码示例和教程

## 使用建议

- **学习编程**：freeCodeCamp、Stack Overflow
- **技术博客**：掘金、Dev.to、Medium
- **问答交流**：Stack Overflow、思否、V2EX
- **代码托管**：GitHub
- **技术资讯**：Hacker News、InfoQ、DZone
- **社区讨论**：Reddit、知乎、开源中国
